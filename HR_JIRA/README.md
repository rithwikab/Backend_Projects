# HR JIRA Backend

A backend system for managing issues and tasks, similar to JIRA.

---

## 🚀 Features

- REST API structure
- Modular routing
- Middleware support
- Organized backend architecture

---

## 📁 Folder Structure

- `routes/` → API endpoints
- `models/` → Data models
- `middleware/` → Request/response handling
- `public/` → Static assets

---

## 🛠 Tech Stack

- Node.js
- Express.js

---
