# Backend Projects

This repository contains backend systems built using Node.js and Express. Each project demonstrates structured backend development with routing, middleware, and service layers.

---

## 📁 Projects

### 1. hr-jira
A backend system for issue tracking, inspired by JIRA.

**Features:**
- RESTful API design
- Modular routing and middleware
- Scalable folder structure

---

### 2. payments-reconciliation
Backend service for handling payment reconciliation and processing.

**Features:**
- Service-based architecture
- Background processing logic
- Clean separation of concerns

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB (or your DB)
